# `db.php` — Conexión a la base de datos

Archivo raíz que establece la conexión con MariaDB. Es incluido por todos los archivos PHP que necesitan acceder a la base de datos mediante `require_once '../db.php'`.

---

## Código completo comentado

```php
<?php
// IP de la VM db dentro de la red intnet_db (10.0.0.0/24)
$host = "10.0.0.100";

// Usuario PHP con permisos limitados solo a la BD del proyecto
$user = "rtg_php";

// Contraseña del usuario rtg_php
$pass = "CambiarPasswordPHP!";

// Nombre de la base de datos
$db   = "proyecto_asir";

// Se crea la conexión con MySQLi (extensión de PHP para MySQL/MariaDB)
// mysqli(host, usuario, contraseña, base_de_datos)
$conn = new mysqli($host, $user, $pass, $db);

// Si la conexión falla, se detiene la ejecución y se muestra el error
// connect_error devuelve null si la conexión fue correcta
if ($conn->connect_error) {
    die("Error de conexión: " . $conn->connect_error);
}

// Se establece el juego de caracteres UTF-8 para evitar problemas
// con tildes, eñes y otros caracteres especiales
$conn->set_charset("utf8mb4");
?>
```

---

## Notas

- La IP `10.0.0.100` solo es accesible desde dentro de la red `intnet_db` (web1, web2 y db). Nunca está expuesta a internet.
- El usuario `rtg_php` solo tiene permisos de `SELECT`, `INSERT`, `UPDATE` y `DELETE` sobre `proyecto_asir`. No puede borrar tablas ni acceder a otras bases de datos.
- `utf8mb4` es la variante completa de UTF-8 que incluye emojis y caracteres especiales de todos los idiomas.
